# Task 9 — Descriptive Statistics Primer (Titanic Dataset)

**Internship task:** Calculate and interpret mean, median, mode, standard deviation, and percentiles for key numeric columns.

## Tools used
- **Python** for analysis and automation
- **Pandas** for data loading, cleaning, and descriptive statistics
- **Excel** (`outputs/titanic_descriptive_statistics.xlsx`) for the deliverable workbook

## Run on Windows (VS Code / Command Prompt)
1. Extract the ZIP file.
2. Open the extracted `Task9_Descriptive_Statistics_Titanic` folder in VS Code.
3. Open Terminal → New Terminal.
4. Install packages:
   ```bash
   python -m pip install -r requirements.txt
   ```
5. Run the analysis:
   ```bash
   python analysis.py
   ```
   The first run downloads the public Titanic CSV into `data/titanic.csv`. Internet is required only for that first download.
6. Open `outputs/titanic_descriptive_statistics.xlsx` in Microsoft Excel. It contains summary statistics, missing values, and group comparisons.
7. Optional interactive dashboard:
   ```bash
   streamlit run app.py
   ```

## Dataset
The project uses the public 891-row Titanic dataset from the seaborn-data repository:
https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv

The dataset has passenger information including survival, passenger class, age, fare, family counts, and embarkation details. This project is descriptive analysis only; it does not build a prediction model.

## Analysis workflow
1. Load the CSV with Pandas.
2. Inspect shape, columns, data types, and missing values.
3. Select numeric columns: `survived`, `pclass`, `age`, `sibsp`, `parch`, and `fare`.
4. Calculate count, missing count, mean, median, mode, standard deviation, minimum, 25th percentile, 50th percentile, 75th percentile, and maximum.
5. Create a cleaned analysis copy, filling missing numeric values with each column's median for the summary workbook. The raw dataset is kept unchanged.
6. Export Excel and CSV deliverables and write an interpretation report.

## Key concepts
- **Mean:** arithmetic average; sensitive to unusually large/small values.
- **Median:** middle value; more resistant to skew and outliers.
- **Mode:** most frequently occurring value.
- **Standard deviation:** typical spread around the mean; larger values indicate more variability.
- **Percentiles:** the 25th and 75th percentiles mark the middle 50% range (IQR = Q3 − Q1).

## Troubleshooting
- **`python` is not recognized:** try `py analysis.py` or install Python 3.10+ and enable “Add Python to PATH”.
- **Package missing:** run `python -m pip install -r requirements.txt`.
- **Download fails:** check internet access, then run `python analysis.py` again. You can also manually download the CSV from the dataset URL above and save it as `data/titanic.csv`.
- **Excel output missing:** check that the script finished without an error; the output is generated by `analysis.py`.
